# Furnace

::: infobox
title = Furnace
image = static/icons/w98_gears.png
caption = A stone furnace
Type = Machine
Category = Processing
Input = Iron ore + fuel
Output = Iron plate
:::

{{stub}}

A **furnace** is a machine that smelts raw ore into refined metal. It consumes fuel and runs a single recipe at a time.

## How it works

Feed a furnace with ore and fuel. It stops automatically when its output buffer is full.

## Recipes

| Input | Fuel | Output |
| ----- | ---- | ------ |
| Iron ore | Coal | Iron plate |
| Copper ore | Coal | Copper plate |
| Stone | Coal | Brick |
