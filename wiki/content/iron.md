# Iron

**Iron** is a refined metal produced by smelting iron ore in a [furnace](furnace.html).

## Production

| Stage | Machine | Output |
| ----- | ------- | ------ |
| Extract | Drill | Iron ore |
| Smelt | Furnace | Iron plate |

## Uses

- Crafting machine parts
- Structural components
