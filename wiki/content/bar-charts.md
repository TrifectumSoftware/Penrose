# Bar Charts

Bar charts render as inline SVG with labeled horizontal bars.

## Syntax

```
::: barchart
title = Chart Title
Item A = 100
Item B = 80
Item C = 60
:::
```

## Example: Production Output

::: barchart
title = Hourly Production
Drill array = 480
Smelter line = 360
Assembly hall = 240
Research lab = 120
:::

## Example: Fuel Comparison

::: barchart
title = Fuel Energy Density (MJ/kg)
Coal = 24
Coke = 29
Wood = 16
Oil = 42
Hydrogen = 120
:::

## Example: Storage Usage

title = Warehouse Capacity
