# Scatter Plots

Scatter plots show correlations between two variables. Use `x,y` pairs.

## Syntax

```
::: scatterplot
title = Correlation
Dataset = 1,2 3,5 5,8 7,11 9,14
:::
```

## Example: Drill Depth vs Output

::: scatterplot
title = Drill Depth vs Output Rate
Small drill = 5,12 8,18 10,22 12,25 15,28
Large drill = 5,30 8,42 10,50 12,55 15,60
:::

## Example: Furnace Temperature vs Quality

::: scatterplot
title = Smelting Temperature vs Plate Quality
Quality rating = 800,45 900,62 1000,78 1100,89 1200,95 1300,97 1400,96
:::

## Example: Belt Speed vs Throughput

::: scatterplot
title = Belt Speed vs Item Throughput
Items/min = 1,10 2,20 3,30 4,38 5,45 6,50 7,53 8,55
:::
