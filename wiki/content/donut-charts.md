# Donut Charts

Donut charts are pie charts with a hollow center, useful for showing proportions while leaving room for a total or label.

## Syntax

```
::: donut
title = Breakdown
Segment A = 40
Segment B = 30
Segment C = 20
Segment D = 10
:::
```

## Example: Factory Resource Allocation

::: donut
title = Resource Allocation
Extraction = 35
Processing = 25
Research = 20
Logistics = 12
Maintenance = 8
:::

## Example: Time Budget

::: donut
title = Shift Time Distribution
Active production = 55
Maintenance = 15
Setup changes = 12
Idle time = 10
Breaks = 8
:::
